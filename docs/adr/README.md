# Architecture Decision Records

Use one ADR for each durable decision that materially affects compatibility, authority semantics, capture evidence, or downstream ingestion.

## Template

```markdown
# ADR-NNNN: Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

## Decision

## Consequences

## Alternatives considered

## Validation
```

Accepted ADRs are immutable except for typo/link corrections. A changed decision receives a new ADR that supersedes the previous one.
